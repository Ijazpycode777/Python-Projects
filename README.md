# Python Task Manager

A simple command-line task manager built with Python.

## Features

- Add tasks
- Delete tasks
- View tasks
- Mark tasks as completed
- Unmark completed tasks
- Display completed and remaining tasks
- Automatically saves tasks to a text file

## Technologies Used

- Python 3

## How to Run

Run:

```bash
python lists.py
```
