Student Management System (OOP)

A console-based Student Management System built in Python using Object-Oriented Programming (OOP). This project was created to practice designing classes, organizing code, and managing student records.

Features

- Add new students
- View student records
- Search students
- Update student information
- Delete student records
- Menu-driven interface
- Object-oriented code structure

Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- Classes and Objects
- Functions
- Lists and Dictionaries (if used)

Project Structure

student-management-system/
│── main.py
│── student.py

(Adjust the structure if your project uses different filenames.)

How to Run

1. Clone the repository:

git clone <repository-url>

2. Open the project folder.

3. Run:

python main.py

Learning Objectives

This project was created to practice:

- Creating and using classes
- Constructors ("__init__")
- Methods and objects
- Encapsulation of data
- Organizing code with OOP
- Building a complete menu-driven application

Future Improvements

- File handling for permanent storage
- Database integration (SQLite/PostgreSQL)
- Student login system
- GPA calculation
- Attendance management
- Subject and marks management
- Graphical User Interface (GUI)
- REST API support

This project is intended for learning Object-Oriented Programming concepts and demonstrates how a simple student management application can be designed using Python.
